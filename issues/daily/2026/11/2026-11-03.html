November 3, 2026 Tuesday edition

Half of Slack messages now come from apps and agents, Salesforce says

The same day brought an agent kill switch from CrowdStrike, Siri AI for every developer, a way to prove which model produced an answer, and a coding-agent trust incident at Postman.

What matters today

SLACK BY THE NUMBERS

Salesforce published Slack usage figures that show how much of the traffic is automated: 127 million MCP tool calls a week, doubling quarter over quarter.

  • 1.9 million users interact with third-party agents in Slack every week.
  • Users send 1 billion messages a day, and more than 100,000 customers have joined Slack so far in 2026.
  • Salesforce calls Slackbot the fastest-adopted AI product in its history; 83% of Salesforce employees use it weekly and 90% of its sellers use it to update Salesforce.
  • Nine of the 10 top frontier AI companies run on Slack by Salesforce’s count, and 65% of Anthropic’s code changes ship through Slack.
  • These are company-reported numbers. The post gives no time period or method for the half-of-messages figure.

AGENT KILL SWITCH

CrowdStrike announced an AI Kill Switch in Falcon Guardian: an administrator can terminate a running agent, block it from relaunching and cut its network access.

  • Available now at the AI Gateway, with endpoint enforcement described as coming soon. Every action is written to the audit trail.
  • Agent-Level Hooks enforce policy inside Claude Code, OpenAI Codex, GitHub Copilot, Microsoft 365 Copilot, OpenCode and Cursor.
  • AI Supply Chain Protection looks for malicious skills and MCP servers; the Falcon sensor now runs inside the Claude Cowork virtual machine.
  • Announced, not yet available: Agentic Identity (identity-aware controls over what agents can access) and coverage for cloud agent frameworks including AWS AgentCore.
  • CrowdStrike also agreed to acquire Fiddler (agent observability) and Dreadnode (automated AI security testing); its releases give no prices.

SIRI AI

Apple opened Siri AI to all developers through a Developer Preview in the iOS, iPadOS, macOS and visionOS 27.3 betas.

  • Any app can bring its content and actions into Siri AI using App Intents.
  • New skills let developers teach Siri AI to combine several actions into a single experience.
  • Siri AI can now surface any entity in the Spotlight semantic index, not only ones that fit an existing schema.
  • Stage: developer preview. Apple says it ships to customers in a few months, with App Store submission opening in the spring.
  • Not available in the EU on iOS, iPadOS and watchOS. Server-side features have daily limits, with paid expanded access planned.

PROVABLE INFERENCE

Anthropic released FlashProve, an open-source prototype that lets a provider prove a response came from a specific model without revealing its weights. The post is dated November 2 and was announced on November 3.

  • On Llama 4 Maverick (400B parameters, 4-bit weights), one H100 GPU generates proofs at about 110 tokens per second.
  • Proof size is about 19 MB per 1,024-token request. Proving costs about 70 to 95 times the GPU time of running the model itself on vLLM.
  • Co-authors come from EPFL, MIT, StarkWare, RESI and Succinct; the security claims are stated in Lean so they can be audited.
  • Code, Lean proofs and documentation are released under Apache 2.0 at github.com/anthropics/FlashProve.
  • Stage: research. Anthropic calls it intermediate progress, with no plans to deploy it.

AGENT CONFIG TRUST

A developer’s bug report says Postman’s desktop app installed plugins into Claude Code and OpenAI Codex without asking. It was the most discussed developer story of the day.

  • Postman 12.33.4 on macOS logged the install on October 24 as auto-existing-upgrade; the issue was opened October 25.
  • In Codex, ~/.codex/config.toml gained an enabled Postman plugin, a plugin marketplace and a trusted session-start hook.
  • The installer writes the hook’s trusted hash into the config itself. Postman’s documentation says its installer can approve the hook on the user’s behalf.
  • Only one macOS install is documented and it has not been independently reproduced. The report shows no evidence that data was collected or sent.
  • Postman had not responded publicly when the story was reported.
  • Discussion thread: 1,493 points and 487 comments.

Research worth watching

  • CoworkOS: Scaling Agent Coworkers

    Long-horizon agent harness that separates task strategy (the model) from execution management (the runtime), with subagent delegation and documents, decks and CAD models that humans and agents edit together. Authors report it is competitive with Codex and DeepSeek Harness across 12 benchmarks.

  • Measuring AI Agents as Teammates

    Stanford benchmark of 240 tasks across 8 dimensions of teamwork. The best of 18 models scores 82.2 out of 100; frontier models reach the best overall deal in only 14% of conflicts, and pass rates fall from 97% to 81% when they take over a task in which a weaker model cheated.

  • CUA-Master

    Nested recursive-improvement loop for computer-use agents that mines real workflows from instructional videos. The 27B model scores 80.2 on OSWorld Verified and 36.9 on OSWorld 2.0, per the authors.

  • Advances in Agentic Computer Graphics

    Report proposing one taxonomy for LLM agents that generate and refine graphics code, plus an agentic literature system to track the field. Most upvoted paper of the day (134 upvotes).
