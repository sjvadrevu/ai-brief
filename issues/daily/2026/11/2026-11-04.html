Salesforce brings Agentforce Coworker into Microsoft Teams

Elsewhere: Claude begins vouching for employees to MCP services, an OpenAI pipeline finds and patches Linux kernel flaws on its own, three coding-agent startups are acquired, and Cloudflare gives sites per-agent controls.

What matters today

COWORKER IN TEAMS

Salesforce announced Agentforce Coworker for Microsoft Teams: an employee hands it a job in a Teams conversation and it coordinates Agentforce agents under the same Salesforce permissions and governance.

  • Stage: Salesforce lists Coworker in Teams, apps for iOS, Mac and Windows, and a Coworker MCP server as generally available in November 2026.
  • Available now: Google Workspace and Microsoft 365 connections for email, calendars and files, Conversation History, reusable Skills, and a $50 per user per month price.
  • Expected in December 2026: scheduled tasks and a Daily Digest of priorities.
  • Salesforce reports more than 185,000 users and 21x growth in usage in three months. The post gives no starting figure and does not define usage.
  • Named customers: Fulton Bank (more than 20 use cases, about 3,000 users), The Adecco Group (expanding across 40 countries) and BACA Systems.

CLAUDE AS ISSUER

Claude can now issue the signed identity assertions that MCP services use to recognize a company’s employees, so plugins connect with no per-user consent screen and no support needed from the company’s identity provider.

  • Announced November 3 and reported the next day. Stage: beta for Claude Team and Enterprise plans. Anthropic calls the feature auto-connect.
  • It builds on the MCP Enterprise-Managed Authorization extension, where the assertion had to come from the identity provider; Okta was the only provider supporting it at launch.
  • Each Claude organization gets its own issuer URL under identity.anthropic.com. The connected service validates the signed JWT and returns an access token.
  • Admins pick which services to enable and which roles get them. 14 services joined at launch, among them Atlassian, Notion, Figma, Linear, Dropbox and Datadog.
  • Supabase’s setup notes state the trade-off: Claude checks organization membership and email only, not MFA, and disabling a user in the identity provider no longer cuts off access.

KERNEL EXPLOIT PIPELINE

OpenAI described an autonomous pipeline that found, validated and wrote patches for 948 local privilege-escalation vulnerabilities in the Linux kernel.

  • Five stages: discovery, reproduction in a sandbox, exploitability assessment, patch generation, then human review before anything is reported to maintainers.
  • In one run in mid-October the agents analyzed 2,308 candidate findings and reproduced 1,724 of them, as quoted in this report.
  • OpenAI put the cost at $1,213,430 in API credits, or $1,279 per working exploit, and says the agents used at least 10 new exploitation techniques.
  • Its conclusion: a low-privileged account on a system that is behind on patches should be treated as root access for a well-resourced attacker.
  • Stage: research. The figures are OpenAI’s own, and the cyber model used in the run has not been released.

CODING AGENT DEALS

OpenAI will acquire Pierre Computer Company to expand the tools Codex has for building, understanding and reviewing code, on a day when two other coding-agent startups were also acquired.

  • Pierre runs a code storage service built for agents and maintains the open-source Trees and Diffs libraries used in the Codex interface. Terms were not disclosed, and the libraries stay open source.
  • Conductor is joining Meta. Its app runs teams of coding agents in parallel workspaces. Sign-ups are closed, Conductor Cloud shuts down November 20, and the local app gets fixes until early 2027.
  • Meta confirmed the deal and gave no terms. Conductor’s founder says a new product is coming early next year.
  • Factory acquired HumanLayer, will open-source it, and plans to add multiplayer workstreams and shared editing of agent-written plans and specs within weeks.
  • Stage: all three are announced. No buyer gave a price.

PERSONAL AGENT TRAFFIC

Cloudflare launched analytics and per-agent access policies for personal agents, the assistants that browse, sign in and buy on a person’s behalf.

  • Security Analytics gains a Personal Assistants category: which agents visit a site, how many requests each sends, the paths they request and the errors they hit.
  • With Account Abuse Protection (early access), a site can see which user each agent represents and whether an agent made a given login or sign-up.
  • A fraud team can act on one account’s agent through its hashed user ID without blocking that agent for everyone else.
  • The Agents policy can now be set for each supported agent: allow, block on pages with ads, or block. Search and Training policies are unchanged.
  • Stage: launched. The post does not list the supported agents. Cloudflare says carrying user context through an agent is its next goal.

Research worth watching

  • Route Anything

    Study of routing each input to the best model or policy, built on 374,401 scored runs from 452 candidate configurations over 25 benchmarks. The authors report learned routers beat the best fixed candidate by 0.3 points across 16 benchmarks and that routing raises efficiency 8.82x on average. Most upvoted paper of the day.

  • ToolSpace

    Builds training and test environments for tool-using agents from execution traces of real MCP services instead of synthetic databases. The authors report its harder versions of two agent benchmarks cut the scores of 7 frontier models by up to 38.2 points, and that its data lifts GLM-5.2 from 44.6 to 56.6 on seven long-horizon suites.

  • EvoTeam

    Multi-agent framework that evolves team organization, interaction rules and individual agent skills together, and keeps a library of reusable teams. The authors report gains on four benchmarks; the abstract gives no numbers.

  • WebHarbor

    153 dockerized reconstructions of real websites with 3,518 tasks, including multi-step and post-login workflows, for training and testing web agents. The authors report that a 4B-class agent trained only inside WebHarbor is competitive with leading open-source web agents.
